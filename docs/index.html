Why a Xiaomi-only debloater?

640+ Xiaomi packages

Every package gets a plain-English description and a safe / caution / danger rating, for MIUI 12–14 and HyperOS 1, 2 and 3.

Updated for new releases

The app downloads the latest package list, so new HyperOS bloat is recognised without reinstalling.

Reversible

Apps are removed for your user only. Restore any of them from the Removed tab.

No root needed

Everything runs over ADB with USB debugging. Your bootloader stays locked and OTA updates keep working.

How to debloat MIUI or HyperOS

  1. Install ADB: brew install android-platform-tools (macOS), winget install Google.PlatformTools (Windows) or sudo apt install adb (Linux).
  2. On the phone, open Settings > About phone and tap MIUI version or OS version 7 times.
  3. Turn on Settings > Additional settings > Developer options > USB debugging.
  4. Connect by USB and tap Allow on the phone.
  5. Open Xiaomi Debloater, start with the Bloatware tab, and remove packages marked safe.

FAQ

Is it safe to debloat a Xiaomi phone?

Packages are removed for the current user only, so they can be restored. Packages marked danger can break calls, SIM, Settings or booting; leave them alone and back up first.

Do I need root or an unlocked bootloader?

No. Xiaomi Debloater works over ADB with USB debugging enabled.

How do I restore a removed app?

Use Restore in the app's Removed tab, or run adb shell cmd package install-existing <package>. A factory reset also restores everything.

Does it work on HyperOS 3?

Yes. The list includes HyperOS 3 packages from the Xiaomi 15 Ultra and is shared by most current Xiaomi, Redmi and POCO models. Missing a package? Report it.

How is this different from Universal Android Debloater?

UAD-ng covers every brand. Xiaomi Debloater focuses on Xiaomi only, tracks packages per MIUI/HyperOS version, and includes a Xiaomi-specific guide.
